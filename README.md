# For Princess Mya 💖 (v2.0)
Open `index.html` in Spck Editor and tap Run/Preview.

- `data/content.js` : edit the letter, reasons, wishes and quiz
- `assets/images/` : her photos (mya1-6.jpg), swap any of them
- `pages/` : one file per page (22 pages)
- `css/` and `js/` : styles, music, particles, games
